# 闲鱼小后台

在本机围绕自己的商品处理素材、观察、发布预览、订单核对与付款后交付。项目自有后台与平台适配器独立运行，不将公共挂牌数当作真实成交或曝光。

这是经清理的公开核心源码起点。没有发布原运营历史、客户、订单、Cookie、账号密钥、商品素材、售卖成品、网盘分享链接或第三方源码副本。原本机仓库及尚未提交的工作保持不变。本仓库中的默认账号和商品 ID 都是合成占位，不能用来操作真实商品。

## 启动

需要 Python 3.12 和 `requirements.txt` 中的依赖。创建本项目虚拟环境并安装依赖后，运行 `python scripts/xianyu-console.py serve`，浏览器打开 `http://127.0.0.1:8090`。只监听本机，不可未经安全改造开放公网。

账号连接需要自己合法持有的网页登录上下文和本机 CDP。平台要求登录或校验时停止，不绕过限制。当前公开源码不含可登录账号，也没有授权它向任何真实客户发送消息。

## 使用与配置

商品与订单读取、发布预览、单次提交和不确定结果回查分别处理。数字成品付款后交付仍需平台订单核对，买家一句“已付款”不能触发；定制服务需要人工制作和验收。

请自行配置 `console/paths.py` 的账号、CDP与目标商品，及自己的商品目录 `products/monetization/catalog.json`。公开起点提供空目录，不含原商品或任何交付包；材料缺失时必须显示缺失，不能据此生成发货或重复发布。消息总开关和交付规则需要逐项审核后启用。

可选夸克交付适配器需要另行安装官方工具和完成自己的授权，来源在 `sources/quark-cli.json`。原第三方后台迁移入口只在你确有对应本地数据库时适用，本仓库不分发该后台或账号数据。

## 数据与边界

`data/console/` 中的 SQLite、`.account.key`、浏览器目录、分享与回执都必须留在自己的机器并一起备份。`data/`、`products/`、`vendor/`、运行日志和构建目录排除 Git。

平台接口属于网页版内部协议，可能失效。完整 SKU、真实付款交付、多账号、多电脑并发等不能由隔离测试推定已验证。源码公开和商品线上发布是两回事。

## 验证与许可

`python -B -m unittest discover -s tests -p 'test_owned_*.py'` 验证合成样本下的业务路径；不连接真实账号。当前仅公开源码，未新增开源许可证。外部项目只作为协议参考，未将其源码或售卖素材复制进此仓库。
